# Audio Files

Place your rain and forest ambient sound files here:

- `rain-gentle.mp3` - Gentle rain sounds
- `rain-heavy.mp3` - Heavy rain sounds (optional)
- `forest.mp3` - Forest ambient sounds (optional)

You can download free rain sounds from:
- https://freesound.org/
- https://pixabay.com/sound-effects/search/rain/
- https://www.zapsplat.com/

Make sure the files are in MP3 format for best browser compatibility.

Note: The app will work without audio files, but the audio player will show an error in the console.
